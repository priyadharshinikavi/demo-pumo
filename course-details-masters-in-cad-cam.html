Masters In CAD/CAM Syllabus

Advanced Mechanical Design & Manufacturing • 6 Months Program
6 Months

Module 1: AutoCAD (2D Drafting & Isometric/Orthographic Views)

Establish technical drafting fundamentals, layouts, isometric modeling, and orthographic documentation.

1. INTRODUCTION TO CADD 60 Mins

CADD WCS, UCS, Product Life Cycle Management, Types of Views, Shapes and Size Factor, Dimensions, Tolerances, GD&T Concept, Angle Of Projections.

2. AUTOCAD INTRODUCTION 60 Mins

AutoCAD User Interface, New, Open, Save, Save as, Plot, Close, Ribbon bar, Status bar, Command line, Layer Properties, Color, Line Type, Line Weight, Units, Limits, Dimension Style. Drawing Simple Sketches: Line, Arc, Circle, Ellipse, Elliptical Arc, Rectangle, Polygon. Dimension Measurements: Linear, Aligned, Arc Radius, Diameter, Arclength, Area. Editing Commands: Erase, Oops, Undo, Redo, Move, Copy, Rotate, Array, Mirror, Fillet, Chamfer, Scale, Stretch, Offset, Trim, Extend. Uses of Function Keys (F keys).

3. PRACTICE 2D SKETCHES 300 Mins

Practice the given Sketches as per dimensional constraints and geometrical constraints.

4. UNDERSTANDING ISOMETRIC VIEW 30 Mins

Purpose of Isometric View, Sketching Isometric Sketches using Autocad tools, Iso circle, Iso plane changing, Dimensioning for Isometric Drawing.

5. PRACTICE ISOMETRIC MODELLING 300 Mins

Practice the Isometric Modelling as per the dimensions.

6. UNDERSTANDING ORTHOGRAPHIC VIEW 30 Mins

Understanding Orthographic Concept, Drafting Settings (DS), Iso plane Change on/off (F5), Copy (CO), Ellipse (EL), Oblique Dimension.

7. PRACTICE ORTHOGRAPHIC MODELS 240 Mins

Practice orthographic models, Understanding difference between First Angle and Third Angle Projections.

8. DRAFTING 60 Mins

Import 3D File, 2D Orthographic views for Import 3D Model, GD&T Symbols apply.

9. FINAL TOOL TEST 120 Mins

2D Sketch with Dimensional and Geometrical Constraints, Isometric Modelling, Orthographic views.

Module 2: SolidWorks (3D Modeling, Assembly, Sheetmetal & Advanced Design)

Design parametric parts, execute advanced mating constraints, model complex sheet metal profiles, and compile detailed production drafts.

1. INTRODUCTION TO SOLIDWORKS 60 Mins

SolidWorks GUI, Feature manager, Callouts, Keyboard shortcuts & Command Manager. 2D SKETCHING: Features of Solid Works, File conversion, Sketch entities, Inference line, Centerline. SKETCH TOOLS: Sketching Lines, Rectangle, Circle, Arc, Slots, Polygon, Ellipse, Spline, Text, Point, Palette.

2. MODIFIER SKETCHER GEOMETRY 60 Mins

Trim, Extend, Fillet, Chamfer, Delete Segment, Offset, Corner, Move, Copy, Rotate, Mirror, Resize, Rapid Sketch, Snap, Grid. Construction geometry, Close sketch to model, Sketch picture, Area hatch/Fill, Sketch pattern, Blocks, Relations, Automatic relations. Dimensioning: Fully define sketch, Sketch diagnosis, 3D Sketching.

3. PRACTICE 2D SKETCHES 480 Mins

Practice the given 2D sketches with dimensional and geometrical constraints.

4. 2D SKETCH ASSESSMENT 1 30 Mins

Complete the sketches with proper dimensional and geometrical constraints in given time.

5. PART MODELLING - BASIC 60 Mins

Extrude, Extrude Cut, Round, Chamfer, Mirror, Plane Offset, Point. Reference Geometry (Plane, axis, center Line), Coordinate System.

6. PART MODELLING ADVANCED 60 Mins

Revolve, Revolve Cut, Swept, Loft, Boundary Blend, Swept Blend, Hole wizard, Shell, Wrap, Intersect, Draft, Rib, Patterns, Split, Project, Composite curve, Curve through point, Helix and spiral.

7. PRACTICE PART MODELLING 600 Mins

Practice the part modelling as per the requirements.

8. PART MODELLING ASSESSMENT 2 60 Mins

Complete the given part model as per the requirements in given time.

9. ASSEMBLY 60 Mins

Top Down & Bottom Up Assembly Concept, Degrees of Freedom Concept, Assembly approaches: Standard, Advanced, Mechanical Mates, Editing, Replacing, Rotating, Assembly pattern and Mirror, Explode views, Physical simulation, layout sketch.

10. PRACTICE ASSEMBLY MODELS 300 Mins

Practice the Assembly models with required constraints and matings.

11. ASSEMBLY ASSESSMENT - 3 60 Mins

Complete the tool test as per the requirement in given time.

12. SHEETMETAL BASICS 60 Mins

Concepts in Sheet metal design: K-factor, Bend allowance, Bend deduction, Neutral Axis, Base flange, Sheet metal tab, Edge flange, Miter flange, Hem, Jog, Rib, Forming tools, cross break, Swept Flange, Closed corners, Welded Corner, Break Corner/Corner Trim, Corner Relief, Extruded Cut, Simple Hole, Sketched bend, fold/unfold.

13. SHEETMETAL - ADVANCED 60 Mins

Loft Bend, Sheet metal Gusset, Tab and slot, Vent, Mirror, Normal Cut, Design Library, Forming tools, Conversion of solid body to sheet metal, Importing, Feature recognition, 2D - 3D Conversion.

14. PRACTICE SHEETMETAL 300 Mins

Practice the Sheetmetal Models as per the requirements.

15. SHEETMETAL - ASSESSMENT 4 90 Mins

Complete the tool test as per the requirement in given time.

16. DRAFTING BASICS 90 Mins

Introduction of Drafting, Sheet Format, Model view, Projected view, Removed section, detail view, relative view, Standard view, Broken out view, Break View, Crop view, Empty view. Annotation - Creating dimensions: Smart Dimension, Model Items, Center line, Center mark.

17. DRAFTING GD&T APPLY 90 Mins

Datum features, Creating GD&T Symbols & Surface finish, Jog leader, Hole callout, Datum target, Dowel pins, Area hatch, Fill, Cosmetic thread, Balloon, Layers, Working with tables, Bill of materials, Hole table, sheets and templates.

18. PRACTICE DRAFTING MODULES 480 Mins

Practice the drafting modules with required dimensions and GD&T symbols.

19. WELDMENT 60 Mins

Introduction of weldment, 3D Sketch, Structural Member, Trim/Extend, Extruded Boss/Base, End cap, Gusset, Extruded cut, Hole Wizard, Chamfer, Reference Geometry.

20. REVERSE ENGINEERING 60 Mins

3D modeling and drafting from industry, Uses and handling of Measuring instruments.

21. SURFACE MODELLING 60 Mins

Extrude, Revolve, Swept, Loft, Boundary surface, Planar surface, Offset surface, Radiate surface, Extending a surface, Surface fill, Ruled surface, Trimming surface, Mid surface, Replace face, Delete face, Untrim surface, Knit surface, Thickening a surface, Move face.

22. PRACTICE SURFACE MODELLING 180 Mins

Practice the surface modelling using surface tools.

23. SURFACE MODELLING ASSESSMENT 5 60 Mins

Complete the given surface model/plastic component in given time.

24. GEOMETRIC DIMENSIONING AND TOLERANCING 180 Mins

Introduction to GD&T, Datum Features, Surface Finish, Datum Target, GD&T Symbols and its Application.

25. FINAL PROJECT 1260 Mins

Complete the projects as per standard requirements in given time: Customer Drawings-2, Industrial Drawings-2, Reverse engineering-2, Sheetmetal-2, Assembly-2, Process Drawings-2.

Module 3: Mastercam CAM (CNC Machining & Toolpath Simulations)

Design wireframes and solid geometries, define stock boundaries, compile standard and dynamic toolpaths, and execute post-processed G-code outputs.

1. INTRODUCTION TO CAM & MASTERCAM 120 Mins

Mastercam Graphical User Interface: Title bar, Menu bar, Toolbar, Selection bar, Navigators, View orientation, Rotate, pan, Zoom, Coordinate system, WCS, Keyboard accelerators, Dialog box, File management - Creating, opening, and saving files.

2. PRACTICE APPLICATION TOOLPATHS 300 Mins

4 and 5 Axis Toolpath Apply, Create Stock Model, Simulation Check, G code and M Code generation.

3. WIRE FRAME CREATING SKETCHES 120 Mins

Creating Sketches – Line, Arc, Circle, Fillet, Chamfer, Rectangle, Polygon, Ellipse. Editing sketches: trim, extend, offset, project. Creating curves from solids and surfaces (one edge or all edges). Transform tools: move to origin, translate, Dynamic translate, mirror, rotate, roll. Graphic view, appearance, tool paths, managers, display, grid, view sheets.

4. SKETCHES PRACTICE 120 Mins

Creating Sketches – 2D sketches, Sketches Alteration and Changes.

5. SOLID COMMANDS 120 Mins

Cylinder, Block, Sphere, Cone, Torus, Extrude, Revolve, Sweep, Loft, Boolean, Fillet, Chamfer, Solids from Surfaces, Constant Fillet, Chamfer, Shell, Thicken, Draft.

6. SURFACE COMMANDS 120 Mins

Cylinder, Block, Sphere, Cone, Torus, Extrude, Revolve, Sweep, Loft, Surfaces from Solids, Flat Boundary, Revolve, Draft, Net, Trim to curves/surface/plane, Fill, Holes, Extend.

7. DRAFTING 120 Mins

Smart Dimensions, Horizontal, Vertical, Point, Angular, Circular, Parallel, Base Line, Note, label, Multi-edit, Dimensions Edit, Hole Table, Leader.

8. CREATE 3D MODELS 300 Mins

Create 3D Models, Alteration and Modify, Changes.

9. LEVEL AND ATTRIBUTES 120 Mins

Creating new level, renumbering, change level, Move or copy entities to another level, level name & number, Find level geometry, turn on/off, reset.

10. TRANSFORM 120 Mins

Dynamic, Translate, Translate to plane, Rotate, Project, Move to origin, Mirror, Roll entity, Chain, Stretch, Scale, Bounding box.

11. PLANE CREATION 60 Mins

Key mapping and Customize, Create Dynamic planes.

12. LEVEL AND TRANSFORM 240 Mins

Usage of Level, Usage of Transform.

13. MILL / LATHE DEFINE 120 Mins

Define Machine list, Lathe Define Machine list.

14. MILL-TOOLPATHS - 2D 120 Mins

Contour, Drill, Dynamic mill, Face, Dynamic contour, Pocket, Peel mill, Blend mill, Slot mill, Model chamfer, Engrave, Swept 2D/3D, Helix bore.

15. SIMULATOR 120 Mins

Back Plot Verification, post processing, Verify, Simulation, Tool components, Visibility, View ports, Color loop, Collision checking.

16. MILL-TOOLPATHS - 3D 180 Mins

Opti rough, Pocket, Project, Parallel, Plunge, Multi surface Pocket, Area, Roughing, Waterline, Raster, Equal, Scallop, Hybrid, Pencil, Blend, Contour, Flowline, Spiral, Radial.

17. PRACTICE MODEL SIMULATOR 180 Mins

Toolpath Check, Tool Collision Check, Generate G Code and M Code.

18. PRACTICE MILL TOOLPATHS - 2D AND 3D 840 Mins

2D And 3D Model Practice (By Using Level, Transform, Planes), Simulation Check, Tool Collision Check, Cycle Time Check, Post Process G-code Generate.

19. MULTI AXIS PATTERN 120 Mins

Curve, Swarf milling, Unified, Parallel, Along curve, Morph, Flow, Multi surface, Port, Triangular.

20. PRACTICE MULTI AXIS PATTERN 240 Mins

Execute complex multi-axis tooling passes and check for tool coordinates collision.

21. APPLICATION 120 Mins

Deburr, pocketing, 3+2 Automatic Roughing, Project curve, Rotary advanced, Rotary, Swarf Expert, Blade expert.

22. STOCK SETUP 120 Mins

Stock plane, Shape, Display, Solid, Entities, Bounding box, STL file save, File input, Setting change, Stock input, stock model.

23. PRACTICE STOCK SETUP 240 Mins

Stock Model Comparison, STL File Conversion, Add Stock.

24. TURNING TOOLS 240 Mins

Rough, Finish, Drill, Face, Cut off, Groove, Dynamic rough, Thread, Plunge turn, Contour rough, Canned cycle, Pattern Repeat.

25. PRACTICE TURNING MODELS 300 Mins

Apply All Turning Tools, Simulation Check, Stock Add, Cycle Time Check, Post Process Generate.
